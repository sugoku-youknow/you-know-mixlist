# ミックスリスト：Spotify連携の設定手順

「Spotifyに保存」を使えるようにするための設定です。**アプリを作った人（あなた）だけ**が1回やればOKです。
※ 2026年のルールで、持ち主のアカウントが **Spotify Premium** である必要があります。

## 1. Spotify のアプリを作る
1. https://developer.spotify.com/dashboard を開いて、自分のSpotifyアカウントでログインします。
2. 初回は開発者規約への同意を求められるので、内容を確認して同意します。
3. 「Create app」を押して、次のように入力します。
   - App name：ミックスリスト（なんでもOK）
   - App description：友達とプレイリストを作るアプリ（なんでもOK）
   - Redirect URIs：次の2つを登録します（1行ずつ「Add」）
     - `http://127.0.0.1:8190/` （パソコンでのテスト用）
     - 公開用：`https://sugoku-youknow.github.io/you-know-mixlist/`
   - 「Which API/SDKs are you planning to use?」で **Web API** にチェックを入れます。
4. 「Save」を押します。

## 2. Client ID を教える
- できたアプリの「Settings」を開くと **Client ID** が表示されます。この英数字をClaudeに伝えてください。
- アプリに埋め込むので、友達側の設定はいりません。Client ID は秘密の値ではないので、公開されても大丈夫です。
- **Client Secret は使いません。誰にも渡さないでください。**

## 3. 保存できる人を登録する（任意）
- アプリの「User Management」で、Spotifyに保存したい友達の **名前** と **Spotifyに登録しているメールアドレス** を追加します。
- 登録できるのは最大5人です（Spotify開発モードの上限）。
- 登録していない友達も、アーティスト選び、プレイリスト作り、試聴、曲リストのコピーは使えます。保存したいときは「曲リストをコピー」で送ってもらうなどしてください。

## 使い方
- アーティストを選ぶ → 選び方を決める → 「プレイリストを作る」 → 「Spotifyに保存」
- 「公開プレイリストにする」にチェックが入っていると（最初から入っています）、プレイリストのリンクを送れば友達も聴けます。チェックを外すと非公開になり、自分にしか見えません。
- 友達にも曲を追加してもらいたいときは、Spotifyアプリでそのプレイリストを開いて、共同編集者を招待してください（このアプリからは設定しません）。
